# Averden — сборки клиента

Здесь публикуются только готовые сборки клиента для лаунчера альфа-теста. Исходного кода здесь нет.

Скачайте `Averden-Launcher.zip` из [последнего релиза](../../releases/latest), распакуйте и запустите
`Averden-Launcher.exe`: лаунчер сам установит игру и будет скачивать обновления.
Описание изменений каждой сборки — на странице [Releases](../../releases).
